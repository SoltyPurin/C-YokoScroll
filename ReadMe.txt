【ゲーム説明】
斧とナイフを使って敵を倒しながら進む横スクロールアクションゲーム



ゲームの遊び方
→Gキー/ゲームスタートボタンを押してゲームスタート
→ゲームスタート、敵を倒しながら進む
→ゴール

各キーを入力することで即別のシーンに移動する。
Gキーでゲーム画面、Mキーでメニュー画面,Tキーでクリア画面

【操作方法】

・通常状態
左スティック/矢印キー　→　移動

Aボタン/Spaceキー　→　ジャンプ

Xボタン/Cキー　→　武器を投げる

Bボタン/Xキー　→　武器を切り替える

・スケボー状態

スケボー状態では止まることはできません。
左入力/←キー　→　ブレーキ
右入力/→キー　→　加速

その他操作は通常時と同じです
